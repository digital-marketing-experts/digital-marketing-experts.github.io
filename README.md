## Core Technical Benchmarks
- Main-thread task execution budget: < 50ms per task
- Interaction to Next Paint (INP): < 150ms across mid-tier mobile viewports
- Cumulative Layout Shift (CLS): < 0.05
- Structured JSON-LD `@graph` entity validation prior to client-side DOM hydration
